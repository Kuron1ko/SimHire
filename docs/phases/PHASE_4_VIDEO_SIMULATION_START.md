# Phase 4 Video Simulation 起始文档草案

本文档是 Phase 4 的预备起始文档。它不是当前开发阶段的执行指令。

Phase 4 技术风险很高。只有当 Phase 3 的实时语音、意图编排和语音合成足够稳定后，才应进入本阶段。

## 1. 阶段目标

Phase 4 的目标是探索视频合成和线上面试模拟，让用户获得更接近真实远程面试的体验。

理想能力包括：

1. 虚拟面试官视频形象。
2. 面试官口型与语音同步。
3. 面试官表情、姿态和语气匹配。
4. 用户摄像头输入。
5. 面试复盘视频时间线。
6. 多模态评价信号。

## 2. 风险说明

本阶段不保证一定成功。

主要风险：

1. 实时视频生成成本高。
2. 口型、表情、声音同步难。
3. 低延迟和高真实感难以同时满足。
4. 摄像头输入会引入隐私和合规问题。
5. 多模态评价容易产生不可靠或不公平判断。

因此 Phase 4 应先做技术验证，再决定是否产品化。

## 3. 前置条件

进入 Phase 4 前应满足：

1. Phase 2 实时互动稳定。
2. Phase 3 意图编排稳定。
3. Phase 3 语音合成稳定。
4. 面试流程、评价报告和 fallback 均可用。
5. 已明确隐私、数据保存和用户授权策略。

## 4. 非目标

Phase 4 初期不应同时做：

1. 支付系统。
2. 高校端和企业端复杂权限。
3. 大规模招聘 ATS 集成。
4. 未经验证的情绪或性格判断。

## 5. 建议探索顺序

1. 静态虚拟面试官形象加语音。
2. 预渲染或轻量动画面试官。
3. TTS 驱动口型或简单表情。
4. 用户摄像头权限和本地预览。
5. 复盘时间线。
6. 多模态分析试验。

## 6. Phase 3 收尾 agent 必须补充

Phase 3 完成后，重写本文档时至少补充：

1. 当前语音合成 provider 和延迟表现。
2. 当前面试官意图模型。
3. 视频方案候选。
4. 隐私和数据保存规则。
5. Phase 4 的 subagent 拆分。
6. Phase 4 的验收标准。
7. 是否建议进入 Phase 4，或者继续打磨 Phase 3。
